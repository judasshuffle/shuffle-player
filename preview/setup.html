For NAS storage, confirm Docker can read the mounted share. A mapped Windows drive is not automatically accessible to Linux containers. Missing mounts must stop setup, not silently create an empty music folder.

2. Choose your index

The container path must match the paths already in an existing index. Change the Docker mount target to match; we will not rewrite paths or migrate the index. New users can use /music.
